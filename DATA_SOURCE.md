# Data source and integrity

Download `bs140513_032310.csv` from the public BankSim distribution maintained at:

https://www.kaggle.com/datasets/ealaxi/banksim1

The experiment accepts the file only when its SHA-256 is:

`e37006f76d993bfaec3a02d717b4f0bdc1ebfa5d36449e91fb7c07e225278377`

The raw data is not redistributed in this package. Place the downloaded CSV in a location of your choice and pass its path to the run script.

Expected file properties from the reported run:

- Rows: 594,643
- Steps: 0 through 179
- Customers: 4,112
- Merchants: 50
- Fraud labels: 7,200
